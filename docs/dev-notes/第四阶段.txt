## 一、Phase 4 目标

本阶段目标：

> 在 Phase 3 已经完成“当前持仓 + 当前收益计算”的基础上，增加基金历史表现分析、当前持仓历史净值回放，以及 ECharts 基础图表。

注意：

本阶段的“历史收益曲线”必须明确区分：

1. 基金本身的历史净值表现
2. 当前持仓份额 × 历史净值得到的“历史市值模拟”

不能把第二种数据称为“真实历史账户收益”。

因为当前系统还没有交易流水、申购日期、赎回记录，所以无法准确还原用户过去真实的账户资产曲线。

# 四、历史表现指标

对于指定基金，计算：

### 1. 最新确认净值

使用最近一个有效交易日净值。

### 2. 区间起始净值

取对应区间最早有效交易日净值。

### 3. 区间收益率

公式：

```text
区间收益率 =
(最新净值 - 区间起始净值)
÷ 区间起始净值
× 100%
```

使用 Decimal。

不要使用 float 直接计算金额和收益率。

---

# 五、最大回撤

增加最大回撤计算。

定义：

```text
历史最高净值 = 当前日期之前出现过的最高净值

回撤 =
(当前净值 - 历史最高净值)
÷ 历史最高净值

最大回撤 = 所有历史回撤中的最小值
```

最终显示为百分比。

例如：

```text
最大回撤：-12.35%
```

注意：

最大回撤必须基于净值时间序列计算，不能简单用：

最高净值 - 最低净值

# 九、当前持仓历史市值模拟

增加一个接口：

```http
GET /api/portfolio/holdings/{id}/history?period=30
```

注意：

这是：

> 当前持仓份额 × 历史确认净值

得到的历史市值模拟。

不是用户真实历史账户资产。

---

## 计算公式

```text
历史模拟市值 =
当前持仓份额 × 当日基金确认净值
```

例如：

当前：

```text
3000 份
```

某天基金净值：

```text
1.3000
```

则：

```text
模拟市值 = 3000 × 1.3000
         = 3900.00
```

同时计算：

```text
模拟收益 =
模拟市值 - 当前持仓投入成本
```

但是前端必须明确显示：

> “历史市值为基于当前持仓份额的模拟结果，不代表真实历史账户收益。”

# 十、不要误导用户

这是本阶段非常重要的一条。

不要出现：

```text
历史账户收益
真实历史收益
历史实际资产
```

这种容易误导的字段。

建议使用：

```text
历史净值表现
历史模拟市值
历史模拟收益
```

并在前端加入说明：

```text
说明：历史模拟市值按照当前持仓份额回放历史基金净值，
未考虑历史申购、赎回、分红及份额变化，因此不代表真实历史账户资产。
```

# 二十六、开发原则

整个 Phase 4 始终遵守：

> 稳定 > 炫技
> 真实数据 > 假数据
> 可运行 > 代码漂亮
> 正确计算 > 页面效果
> 明确口径 > 看起来很智能

尤其注意：

**任何没有真实数据支持的内容，都不能伪造成真实数据。**
**任何无法准确还原的历史账户数据，都必须明确标记为模拟。**
